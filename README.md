# Customer Churn Prediction

## 📌 Project Overview

This project uses machine learning to predict whether a customer is likely to churn.

Customer churn refers to customers stopping or discontinuing a service. Predicting churn can help businesses identify customers who may leave and take preventive actions.

## 🎯 Objective

The main objective of this project is to:

- Analyze customer information
- Identify factors related to customer churn
- Train a machine learning classification model
- Predict whether a customer is likely to churn
- Evaluate model performance

## 🛠️ Technologies Used

- Python
- Pandas
- Scikit-learn
- Random Forest
- Machine Learning
- Classification

## 🔄 Project Workflow

1. Load the customer dataset
2. Clean and preprocess the data
3. Convert categorical variables into numerical values
4. Separate features and target variable
5. Split the data into training and testing sets
6. Train a Random Forest classification model
7. Generate predictions
8. Evaluate the model using accuracy and classification metrics

## 🤖 Machine Learning Model

I used the Random Forest Classifier because it can handle multiple features and is effective for classification problems.

## 📊 Evaluation

The model is evaluated using:

- Accuracy
- Precision
- Recall
- F1-score
- Classification Report
